# Rana's Table — Restaurant Ordering Platform

A full-stack restaurant ordering web application built with PHP, MySQL, JavaScript, and Bootstrap.

## Features

### Customer Features
- User registration and login
- Email verification
- Forgot and reset password
- Browse food/menu items
- Search products
- Shopping cart
- Checkout
- Place orders
- Order tracking/status
- Customer profile
- View order history
- Payment functionality

### Admin Features
- Secure admin login
- Admin dashboard
- Manage users
- Manage products
- Manage categories
- Update products
- Delete products
- Manage customer orders
- View and manage order status

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- MySQL
- Composer
- Git & GitHub

## Project Structure

- `admin/` — Admin dashboard and management
- `user/` — Customer functionality
- `uploads/` — Uploaded files/images (not included in repository)
- `product_uploads/` — Product images (not included in repository)
- `vendor/` — Composer dependencies (not included in repository)

## Security

Sensitive configuration files and uploaded files are excluded from the Git repository using `.gitignore`.
